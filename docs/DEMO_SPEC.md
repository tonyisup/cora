# Bounded speech-learning demo specification

Status: v3 frozen implementation specification after retained v1/v2 design failures.

This document authorizes a synthetic, deterministic demonstration layer over
the retained Stage 5 plant. It does not reopen H4 continuous inverse closure,
weaken an H4 failure, or authorize protected or recorded speech data.

## 1. Demonstrated behavior

The agent must visibly execute this bounded loop:

1. babble a fixed motor repertoire and retain motor-to-sensory consequences;
2. receive an unlabeled synthetic auditory target;
3. begin from a neutral/rest prototype;
4. explore only a bounded local motor neighborhood;
5. retain the best target-specific motor association found so far;
6. recall that association without further search for the final three attempts;
7. emit target and final self waveforms plus a complete deterministic session
   report.

The agent receives only a normalized 30-dimensional sensory target. Vowel names
are scenario and evaluation metadata and must not enter action selection.

## 2. Frozen plant and memory

- Plant: the retained factorized five-coordinate, ten-section, expanded-band
  deterministic plant.
- Motor coordinates: five values in `[0, 1]`.
- Babbling repertoire: exactly 96 Halton points using start index `14001` and
  stride `37` (last index `17516`). This v3 schedule is disjoint from stopped
  v1/v2 and H4 confirmation ranges. The stride is coprime with every Halton base
  and supplies a wider deterministic space-filling sample without increasing
  memory capacity.
- Sensory representation: the plant's normalized 30-dimensional expanded-band
  log spectral envelope.
- Memory: exactly one sensory consequence per motor prototype and at most three
  target-specific associations. No cross-session unbounded growth.
- F0 for rendered demo artifacts: `110 Hz`.
- Presentation WAV: six identical 160 ms plant productions separated by
  40 ms silence. This repetition changes presentation only, not sensory scoring.

## 3. Frozen scenarios

The demo supports `/a/`, `/i/`, and `/u/` as display/evaluation labels.

### Synthetic mirror

The target is a member of the babbled repertoire, chosen deterministically as
the repertoire prototype nearest to the corresponding fixed target envelope.
This verifies exact bounded recall within the agent's own known action set.

### Cross-configuration

The target is generated by the corresponding already-spent Option F target
motor, which is not a member of the repertoire. The agent must find and remember
an acoustically similar repertoire action. This is prototype association, not a
claim that the original motor configuration was recovered.

## 4. Frozen learning and search loop

- Attempt count: exactly 12 per target.
- Attempt 1: neutral/rest prototype, defined as the repertoire point nearest
  `[0.5, 0.5, 0.5, 0.5, 0.5]`.
- Attempts 2–9: form a local frontier from the 12 nearest untried prototypes
  around every previously tried prototype, then execute the frontier item with
  minimum remembered sensory distance to the target.
- Attempts 10–12: recall the best learned association without exploration.
- Sensory distance: half Euclidean distance between unit-normalized sensory
  vectors.
- Competence progress: decrease in best-so-far sensory distance after each
  executed attempt.

The babbling memory supplies forward consequences for bounded action selection.
The demo does not fit a continuous forward function, compute gradients, or learn
a global or local continuous inverse.

unchanged.

## 5. Frozen success gates

Every target and scenario must satisfy:

- exactly 96 finite, bounded, distinct motor prototypes;
- exactly 12 attempts;
- the learner receives no vowel label;
- final best distance improves at least `30%` over the rest attempt;
- final best sensory distance is at most `0.20`;
- the final three attempts recall the same prototype;
- target-specific association memory remains within three entries;
- target and final waveforms are finite, below full scale, SHA-256 identified,
  and deterministically reproducible;
- no recorded audio, external corpus, live I/O, or protected path is accessed.

The aggregate scenario passes only if `/a/`, `/i/`, and `/u/` all pass.

## 6. Claim boundary

A pass demonstrates that a bounded local agent can use babbling-derived forward
memory to improve synthetic acoustic imitation, store a target-specific motor
association, and recall it deterministically.

It does not demonstrate infant learning, phoneme recognition, anatomical
fidelity, language understanding, generalized acoustic-to-articulatory
inversion, human-speaker imitation, speaker identity, semantics, or continuous
motor/perception closure.

Recorded-human and live exact-efference demo stages require separate frozen demo
specifications after this slice passes. They may use new project-owner
recordings, but not protected corpora.
